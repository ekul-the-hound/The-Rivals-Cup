# Manual operating checklist

The system produces research. You decide and you enter every trade by hand in Trader View.

1. Run the refresh jobs (see `test_and_release_checklist.md`) and open the dashboard health page.
2. Read every STALE / MISSING / bar-issue warning. Fix or accept each one knowingly.
3. Confirm the week's event blackout list; skip names with earnings or major events inside the week.
4. Review the ranked pairs and research packets. Treat news text as untrusted evidence.
5. Check tradability, shortability and liquidity (the 1% of ADV figure is an estimate) in Trader View.
6. Check gross exposure stays under 200% (gross = |long| + |short|; net shown separately).
7. Enter each trade yourself in Trader View.
8. Only after entering, record it in the journal with the "already entered manually" confirmation.
9. Scores shown are ESTIMATED; the Wall Street Rivals leaderboard is authoritative.
10. Each week the book resets to $1,000,000: start a new week and do not carry last week's positions.
